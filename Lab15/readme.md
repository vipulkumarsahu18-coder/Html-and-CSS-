Aim: To use media queries to change a layout, make an image responsive and set text sizes using rem units.

Theory:

Responsive web design is used to make websites adjust to different screen sizes such as mobile phones, tablets and desktops. CSS media queries help apply different styles according to screen width.
1. Responsive Design: Makes websites adjust to different screen sizes.
2. Media Query: Applies CSS styles based on device or screen conditions.
3. @media: Used to define a media query in CSS.
4. Viewport: Defines the visible area of a web page.
5. meta viewport: Helps a web page display correctly on mobile devices.
6. max-width: Sets the maximum width of an element.
7. height: auto: Maintains the original aspect ratio of an image.
8. rem: A relative unit based on the root font size.
9. min-width: Applies styles when the screen width is at least a specified size.
10. Mobile-First Design: Starts designing for smaller screens and then adjusts for larger screens.
Conclusion:

In this practical, we learned how to create responsive web pages using CSS media queries, make images flexible and adjust text sizes using rem units.
