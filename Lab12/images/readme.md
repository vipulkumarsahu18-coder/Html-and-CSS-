Aim: To compare the box sizing types, style a card and make a box scroll.

Theory:

CSS Box Model describes how elements are displayed on a web page. It consists of content, padding, border and margin. CSS also provides properties to create cards and scrolling boxes.
1. Content: The actual text or content inside an element.
2. Padding: Space between content and border.
3. Border: A line surrounding the padding and content.
4. Margin: Space outside the border.
5. box-sizing: Defines how the width and height of an element are calculated.
6. content-box: Width and height apply only to the content.
7. border-box: Width and height include content, padding and border.
8. border-radius: Used to make rounded corners.
9. overflow: Controls what happens when content exceeds an element's size.
10. overflow: auto: Adds scrolling when the content does not fit inside the box.
Conclusion:

In this practical, we learned about the CSS Box Model, compared content-box and border-box, created a styled card and made a scrollable box using CSS.
