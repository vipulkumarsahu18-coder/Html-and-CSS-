# Assignment 7: About Me Page

**Aim:** To build a short About Me page using semantic HTML tags, an About section and a contact link.

### Theory

HTML (HyperText Markup Language) is used to create and structure web pages.

In this practical, we use semantic HTML tags to create an About Me webpage.

1. **Header Tag (`<header>`):** Defines the top section of the webpage.
2. **Navigation Tag (`<nav>`):** Provides navigation links such as About and Contact.
3. **Main Tag (`<main>`):** Contains the main content of the webpage.
4. **Section Tag (`<section>`):** Groups related content together.
5. **Heading Tag (`<h1>`, `<h2>`):** Defines headings on the webpage.
6. **Paragraph Tag (`<p>`):** Displays text information.
7. **Footer Tag (`<footer>`):** Defines the bottom section of the webpage.
8. **Anchor Tag (`<a>`):** Creates hyperlinks.
9. **Mailto Attribute:** Opens the default email application to send an email.

### Conclusion

In this practical, we successfully created an About Me webpage using semantic HTML tags. We added personal information, navigation links and an email contact link using the mailto attribute.
