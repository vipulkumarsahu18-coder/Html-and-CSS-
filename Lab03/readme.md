1. First HTML Page

HTML is used to create web pages. The "<title>" tag sets the title of the browser tab, and the "<h1>" tag displays a large heading.

2. HTML Headings and Paragraph

HTML provides six heading tags, from "<h1>" to "<h6>", to display headings of different sizes. The "<p>" tag is used to write paragraphs.

3. HTML Text Formatting

The "<strong>" tag makes text bold, the "<em>" tag makes text italic, and the "<br>" tag is used to start a new line.
