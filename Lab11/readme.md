Aim: To use CSS units and store colours and spacing in variables.

Theory:

CSS units are used to define the size, width, height, spacing and font size of HTML elements. CSS variables help store reusable values such as colours, font sizes and spacing.
1. px: A fixed unit used to define size.
2. %: A relative unit based on the size of the parent element.
3. rem: A relative unit based on the root element's font size.
4. :root: Defines global CSS variables.
5. CSS Variables: Used to store reusable CSS values.
6. --variable-name: Used to declare a CSS variable.
7. var(): Used to access the value of a CSS variable.
8. width: Defines the width of an element.
9. height: Defines the height of an element.
10. padding: Defines the space inside an element.
Conclusion:

In this practical, we learned how to use CSS units such as px, percentage and rem. We also learned to create and use CSS variables for colours, font sizes and spacing.
