### Aim
To create a Git repository for an HTML lab folder and save the work using Git commits.

### Theory

Git is a version control system used to track changes in files and projects.

A Git repository stores the history of our project. It helps developers manage their code and track previous changes.

**Important Git Commands:**

1. `git init` – Creates a new Git repository.
2. `git config --local user.name` – Sets the username for the current repository.
3. `git config --local user.email` – Sets the email for the current repository.
4. `git status` – Shows the status of files.
5. `git add` – Adds files to the staging area.
6. `git commit` – Saves changes in the repository.
7. `git log --oneline` – Displays commit history in a short format.
