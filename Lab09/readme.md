Aim: To create HTML tables using caption, thead, tbody, tfoot and scope attributes.

Theory:

HTML tables are used to display data in rows and columns. HTML provides different tags to create and organize table data.
1. <table> – Used to create a table.
2. <caption> – Defines the title of the table.
3. <thead> – Defines the header section of a table.
4. <tbody> – Defines the main body of a table.
5. <tfoot> – Defines the footer section of a table.
6. <tr> – Used to create a table row.
7. <th> – Defines a table heading.
8. <td> – Defines a table data cell.
9. scope="col" – Specifies that a header applies to a column.
10. scope="row" – Specifies that a header applies to a row.
Conclusion:

In this practical, we learned how to create HTML tables, display student marks, calculate class averages and make tables more accessible using scope attributes.
