Aim: To apply CSS in three ways (inline, internal and linked) and use selectors and text styles.

Theory:

CSS (Cascading Style Sheets) is used to style HTML web pages. It controls the colours, fonts, sizes, backgrounds and layout of web pages.
1. Inline CSS: CSS applied directly inside an HTML element using the style attribute.
2. Internal CSS: CSS written inside the <style> tag in the head section.
3. External CSS: CSS written in a separate .css file and linked using the <link> tag.
4. Element Selector: Selects HTML elements such as h1 and p.
5. Class Selector: Selects elements using a class name with a dot (.).
6. ID Selector: Selects an element using an ID with a hash (#).
7. color: Changes the text colour.
8. background-color: Changes the background colour.
9. font-size: Changes the text size.
10. text-decoration: Adds underline or other text decoration.
Conclusion:

In this practical, we learned how to apply inline, internal and external CSS and use different CSS selectors to style HTML elements.
