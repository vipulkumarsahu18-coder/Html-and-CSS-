### 1. Layout Using Div

**Theory:** The `<div>` tag is used to create blocks or sections on a webpage. The `class` attribute identifies each block.

- `header`: Represents the header section.
- `main`: Represents the main content.
- `footer`: Represents the footer section.

### 2. HTML Attributes

**Theory:** HTML attributes provide additional information about HTML elements. The `id` attribute uniquely identifies an element, while the `data-*` attribute stores custom data.

- `id="profile"` identifies the div.
- `data-topic="hobbies"` stores information about hobbies.

The custom attribute is not directly visible on the webpage.

### 3. Fixing HTML Errors

**Theory:** HTML tags must be properly opened and closed to display a webpage correctly. Missing or incorrect closing tags can cause errors in the page structure.

In this practical, the missing `</h1>` tag and incorrect paragraph closing tag are corrected to display the heading and both attendance records properly.
