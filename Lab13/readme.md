Flexbox (Flexible Box Layout) is a CSS layout model used to arrange elements in rows or columns. It makes website layouts flexible and responsive.
1. display: flex: Enables Flexbox layout.
2. flex-direction: Defines the direction of flex items.
3. justify-content: Aligns items along the main axis.
4. align-items: Aligns items along the cross axis.
5. flex-wrap: Allows items to move onto the next row.
6. gap: Defines space between flex items.
7. nav: Defines a navigation section.
8. a: Defines hyperlinks.
9. flex-start: Aligns items at the beginning.
10. center: Aligns items in the centre.
Conclusion:

In this practical, we learned how to create a navigation bar, arrange cards in a row, centre items and make cards wrap onto new rows using CSS Flexbox.
