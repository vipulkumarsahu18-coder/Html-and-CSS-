# Assignment 2: Pushing and Cloning a Repository

**Aim:** To send commits to a second repository on the computer and create a copy of it using Git Clone.

### Theory

Git is a distributed version control system used to track changes in files and manage projects.

1. **Git Init --bare:** It creates an empty remote repository without a working directory.
2. **Git Remote Add Origin:** It connects the local repository to another repository.
3. **Git Remote -v:** It displays the remote repository URLs for fetching and pushing.
4. **Git Push:** It sends local commits to the remote repository.
5. **Git Clone:** It creates a copy of an existing repository in a new folder.
6. **Git Log --oneline:** It displays the commit history in a short format.

### Conclusion

In this assignment, we successfully created a bare repository, connected it to the local repository, pushed commits to the remote repository, and cloned it into a new folder. We also verified the commit history using `git log --oneline`.
