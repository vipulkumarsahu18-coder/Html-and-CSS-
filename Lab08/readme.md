# Assignment 8: Sign-Up Forms and Choices

**Aim:** To create a labelled form with text, email and password fields, choices and a submit button using HTML.

### Theory

HTML forms are used to collect information from users. They allow users to enter data, select options and submit information.

In this practical, we use different HTML form elements and attributes.

### Important HTML Tags and Attributes

1. **Form Tag (`<form>`):** Used to create an HTML form.
2. **Label Tag (`<label>`):** Provides a label for an input field.
3. **Text Input (`type="text"`):** Used to enter the user's full name.
4. **Email Input (`type="email"`):** Used to enter an email address.
5. **Password Input (`type="password"`):** Hides the characters entered by the user.
6. **Radio Button (`type="radio"`):** Allows the user to select one option from multiple choices.
7. **Select Tag (`<select>`):** Creates a dropdown list.
8. **Option Tag (`<option>`):** Defines options inside a dropdown list.
9. **Required Attribute:** Makes a field compulsory.
10. **Placeholder Attribute:** Displays a hint inside an input field.
11. **Submit Button:** Submits the form data.

### Form Attributes

- **Action:** Specifies where the form data will be sent.
- **Method:** Specifies how the form data will be submitted, such as GET or POST.
- **Required:** Ensures that the user fills in the compulsory fields.
