Aim: To create a grid with equal columns, a responsive gallery and a layout with named areas using CSS Grid.

Theory:

CSS Grid is a two-dimensional layout system used to arrange HTML elements into rows and columns. It helps create responsive and well-organized web page layouts.
1. display: grid: Enables CSS Grid layout.
2. grid-template-columns: Defines the number and size of columns.
3. grid-template-rows: Defines the size of rows.
4. fr: Represents a fraction of the available space.
5. gap: Defines the space between rows and columns.
6. repeat(): Repeats column or row patterns.
7. minmax(): Defines minimum and maximum sizes.
8. auto-fill: Automatically creates as many columns as can fit.
9. grid-template-areas: Defines named areas in a grid layout.
10. grid-area: Assigns an element to a named grid area.
Conclusion:

In this practical, we learned how to create equal-column grids, responsive photo galleries and dashboard layouts using CSS Grid properties.
